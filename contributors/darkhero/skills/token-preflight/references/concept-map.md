# Minimal concept map

`FAMES` is the public umbrella and standalone trigger. Its execution order is FP -> MTM -> SCF -> AEX -> SEAL; PFKT is an optional MTM work-graph overlay. `AEX` alone remains the narrow cross-cycle evolution phase.

| Phase | Owns | Must not own |
|---|---|---|
| FP | Outcome, Verification, Constraints, semantic hash | execution loop |
| MTM | cost/read budget and route | completion truth |
| PFKT | optional work graph | universal prompt gate |
| SCF | goal/result residual | evidence collection |
| SEAL | completion predicates | another evolution loop |
| AEX | cross-cycle adaptation | one-shot execution |

Completion is one predicate: goal hash matches, required evidence passes and is fresh, and any active work graph is closed. Configuration or probe failure is UNKNOWN.
